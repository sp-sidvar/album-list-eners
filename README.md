## 1. Planificación y Requisitos
### **Definir el objetivo:** 
    Esta aplicacion ayudara a compartir albumes musicales con el publico que desee conocer nueva musica

### **MVP:**
    - Lista de albumes (Conexion con spotify para requisicion de datos)
    - Base de datos con lista de albumes

### **Historias de usuario:** 
    - Como ususario me gustaria poder brindar una calificacion al album que escucho (rank de estrelas)
    - Como usuario me gustaria poder comentar acerca del album que escucho
    - Como usuario me gustaria poder hacer mis propias recomendaciones para que se agregen a la lista

### **Monetización:**
    Aplicacion completamente libre de cargo
